# Бот пиздатых шабашек — Владивосток

Бот сам читает каналы с шабашками и присылает тебе в Telegram только четыре вида:

- 🏨 **ДОРОГОЕ МЕСТО**: отели (BURNY / Rodina на Набережной 13, Rodina Grand Hotel, Lotte, Azimut, Магнум, Версаль), ДВФУ, ВЭФ, топовые рестораны (Улисс Азия, Zuma, Миллионка, Густо, Супра, TiAMA…), яхт-клубы. Там обычно делать мало. Присылает из любого района, от 400 ₽/ч или если цена не указана. Тяжёлую физуху не присылает.
- 🚚 **ПОЕЗДКА**: погрузил, едешь в другой город (Большой Камень, Находка, Уссурийск…), разгрузил и обратно. Почти всё время едешь.
- ✨ **ИНТЕРЕСНОЕ**: съёмки, массовка, большие ивенты, видео и рилсы.
- 📍 **РЯДОМ**: до 30 минут пешком, от **500 ₽/ч**. Обычная погрузка подходит (на карточке будет пометка «физическая работа»). Не присылает фуры, контейнеры, цемент, стройку, смены по 8+ часов и частников «на час-два» (поднять шкаф, переезд, подмести подъезд).

Всё остальное отсеивается, как и разводы: дропы, «курьер документов», «без вложений», «ставь +». Посты с пометкой «Закрыта» тоже пропускаются.

Каналы по умолчанию: `podrabotka_vl`, `vladivostok_atlanta`, `rabota_1vladivostok`, `little_job_VDK`. Они подключаются сами.

**В твой Telegram бот не заходит.** Каналы он читает через открытую веб-версию `t.me/s/канал`, как любой человек без регистрации. На ПК ничего не ставится. Бот работает в облаке GitHub бесплатно и круглосуточно и проверяет каналы раз в ~10 минут.

## Запуск (один секрет, ~10 минут)

1. **Бот.** В @BotFather у тебя уже есть бот и его токен вида `123456789:AAH...`.
2. **GitHub.** Зарегистрируйся на github.com.
3. **Репозиторий.** Нажми **+ → New repository**. Имя `shabashki`, тип **Public**, затем **Create repository**.
4. **Загрузка.** Нажми ссылку **uploading an existing file**. Открой папку `shabashki-bot` из архива, выдели внутри всё (Ctrl+A) и перетащи в браузер. Обязательно вместе с папкой `.github`. На Mac она скрыта: нажми `Cmd + Shift + .`, чтобы её увидеть. Затем нажми **Commit changes**.
5. **Секрет.** Открой **Settings → Secrets and variables → Actions → New repository secret**. В Name впиши `BOT_TOKEN`, в Secret вставь токен, затем **Add secret**.
6. **Telegram.** Открой своего бота и нажми **Start**.
7. **Запуск.** Открой вкладку **Actions**. Если увидишь зелёную кнопку, нажми её. Слева выбери **«Шабашки: проверка»**, затем **Run workflow → Run workflow**. Через 1–2 минуты бот напишет «ты владелец» и пришлёт лучшее за сутки.

Дальше бот работает сам.

**Точнее «сколько идти».** Пришли боту геопозицию дома: скрепка → Геопозиция. Без неё минуты считаются от центральной площади.

## Команды
- `/kanaly` — какие каналы читаю. `/ubrat имя` — убрать канал (сам он больше не вернётся).
- Новый канал: перешли боту любой пост из него или пришли ссылку `t.me/...`.
- `/stavka 600` — минимум ₽/ч для «рядом» (по умолчанию 500).
- `/status` — что с ботом и сколько нашёл за сегодня.
- `/pause` и `/resume` — пауза и снова в бой.

Команды выполняются при следующей проверке, раз в ~10 минут.

**Группы** (где «участники», например gruz4i или «Город услуг») снаружи не читаются. Бот сам скажет, если ты пришлёшь такую.

## Безопасность
- **В Telegram никакого входа.** Твои переписки, контакты и аккаунт боту недоступны.
- **ПК не участвует.** Ни у бота, ни у кого-то ещё нет доступа к компьютеру.
- **В GitHub лежит только токен бота.** С ним можно только писать от имени бота, читать твои чаты он не даёт. Если что-то заподозришь, сделай в @BotFather `/revoke`, а новый токен положи в секрет `BOT_TOKEN`. Бот просто начнёт заново.
- **Состояние зашифровано** (AES-256 + HMAC): список каналов, точка дома, отпечатки постов. В публичные логи пишутся только счётчики.
- **Права в облаке разделены.** Шаг с токеном может только читать репозиторий. Писать может только шаг сохранения, а токена он не видит.
- **Код написан с нуля.** Сторонних GitHub Actions нет. Библиотеки закреплены по версии и SHA-256 (сверено с PyPI). Для публичных каналов работает только стандартный Python плюс `pyaes` для шифрования. Telethon даже не запускается.
- **Нейросеть** (бесплатная, GitHub Models) получает только текст объявления, без телефонов, @ников и ссылок. Решение всегда принимает код.

## Если что-то не так
- **Во вкладке Actions пусто** — не загрузилась папка `.github`. Перетащи её на страницу загрузки отдельно (Add file → Upload files).
- **Бот молчит.** В Actions у «Шабашки: проверка» должны быть зелёные галочки. Напиши боту `/status`. Если шабашек мало, это нормально: в каналах в основном тяжёлая физуха, а её бот режет.
- **Много или мало «рядом».** Подними или опусти `/stavka`.
- Всё можно подкрутить в `shabashki/profile.py`: ставку, «рядом» в минутах, каналы по умолчанию.

## Дополнительно (не обязательно)
| Секрет | Зачем |
|---|---|
| `STATE_KEY` | свой ключ шифрования (длинная случайная строка). Без него ключ берётся из токена бота |
| `OWNER_ID` | твой числовой id в Telegram (покажет @userinfobot): бот слушается только его |
| `CHANNELS` | ещё каналы через запятую |

**Закрытые каналы** (без @имени) читаются только через **отдельный пустой аккаунт** Telegram. Основной аккаунт сюда не подключай никогда. Понадобятся секреты `TG_API_ID`, `TG_API_HASH` (my.telegram.org) и `STATE_KEY`. Затем запусти Actions → «Шабашки: вход (закрытые чаты)» и отсканируй QR в боте **запасным** аккаунтом.

**Свой сервер.** Там проверка идёт раз в минуту, а не раз в 10. Инструкция лежит в `deploy/vps/README.md`.
